## How to Use

### Week 4 onwards (post-content)
1. Start with **Tier 1** HLD problems - whiteboard each in 45 min
2. Pick 2-3 LLD problems per day - code in C++
3. Track progress in [final-checklist.md](final-checklist.md)
4. Schedule 5+ mock interviews - log results in the table at bottom of checklist

### Mock Interview Format
- 5 min: clarify
- 5 min: capacity (HLD only)
- 10 min: high-level design / API
- 20 min: deep dive
- 5 min: scale, failure modes, follow-up questions

### Daily Practice
- One LLD problem (45 min): clarify -> code skeleton -> walk through -> extension question
- One HLD problem (45 min): 6-step framework
- 30 min review: refresh patterns, read 1 design article (HighScalability, ByteByteGo)
